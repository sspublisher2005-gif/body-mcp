## 2. What we shipped in this upgrade

### 2.1 Auto-use (fixes the failure the user actually saw)
- **`body_capabilities()`** — call first. One compact manifest: what works on this
  machine, what is blocked, the EYES→BRAIN→HANDS→VERIFY loop, and WHEN to use
  each tool group. Derived from `body_status()` (no second source of truth).
- **`SKILL.md`** + `AGENTS.md` — hard-code the loop and the rule: if a body tool
  can do it, do not reach for webfetch/websearch.
- **`body_focus(mode)`** — narrows `tools/list` from 81 to 30 (`list_changed`),
  hidden tools stay callable. Default `all` so nothing breaks.

### 2.2 Context economy (new, from the HN research)
- **`body_context_report()`** — measures the live tool schemas in BYTES (not
  guessed tokens), lists the largest schemas, all bounded-output caps, and the
  exact saving from `body_focus`. Measured here: **81 tools = 52 KB**; largest
  single schema = `privacy_session_start` at 2 KB.
- Every research result already carries an evidence record + content hash
  instead of a raw page dump.

### 2.3 Correctness guards (from the external tester's 12 bugs)
- A **real MCP stdio guard** calls 70 tools in a separate process with a hard
  per-call timeout; #1–#3 (tools that crashed only through MCP) now fail CI by
  name. Also asserts bad arguments still return `{success, message, data}`.
- Fixed: `/api/generate` rejects images (describe uses `/api/chat`), a false
  vision claim about `gemma3:270m`, the blocked-source misattribution, and the
  FTS5 hyphen query bug.

### 2.4 Your browser, not a test browser
- First-install grant: `python -m body_mcp.setup` → load `extension/` once →
  click "Connect this tab" once → remembered and auto-reattaches.
- Native host registered in **Chrome, Edge, Brave, Vivaldi and Opera**.
- `own_browser_only` (default `allow`): browser tools return `needs_user` with
  exact steps instead of launching managed Chromium. CI opts out explicitly.
- A login wall is the **user's** decision (`human_choice.decision`): the agent
  never logs in, solves CAPTCHA, bypasses or rotates; if the user declines, it
  picks a safe alternative and says which source actually answered.

### 2.5 Platform maturity
- CI: 3 OSes × Python 3.11/3.12/3.13/3.14 + packaging + stdio guard — **13/13 green**.
- Integration proofs on disposable runners: real Tesseract OCR, ffmpeg learning,
  `qwen3:0.6b` worker, `qwen3-vl:2b` describe — all green. Nothing installed on
  the user's laptop (D17).

## 4. Honest gaps (not fixed by this upgrade)

- Extension bridge, VPN, Whisper, local worker on the user's laptop: mock-only
  until they grant/install; runner proofs exist for the local model paths.
- macOS desktop control: UIA is Windows-only; macOS CI runs the cross-platform suite.
- Reddit/X: platform-blocked; the body now asks you instead of faking a source.
- 8B uncensored model needs ~6 GB RAM; this laptop has ~500 MB free.
- PyPI package not published yet (needs a one-time publisher on pypi.org).

## 5. Why this is strong and light

- **Core dependencies: 2** (`mcp`, `playwright`). Desktop, voice and local-model
  features are optional extras, lazily imported.
- Idle body: ~70 MB RAM, 0% CPU (external tester, Linux 1 core / 4 GB).
- 81 tools implemented, ~30 visible per role — full capability, small surface.
- Free/open forever (MIT), no telemetry, no cloud account, no downloaded model.
